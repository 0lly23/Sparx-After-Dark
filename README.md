How to install:

## Install locally

1. Open `chrome://extensions` in Chrome, or `edge://extensions` in Edge.
2. Enable **Developer mode**.
3. Choose **Load unpacked**.
4. Select this folder (the folder containing `manifest.json`).
5. Open Sparx Maths and use the extension toolbar button to personalise it. The extension supports the current `maths.sparx-learning.com` question pages as well as the older Sparx Maths domain.

Personalisation options:
  You can:
  change the font, roundness of boxes, all UI colour ways to create your own and even share them with sharecodes.
  Go fullscreen for a sleek, focused design.
  Scientific Calculator - unfortunatly has to warn you if you use on non-calculator questions.
  Notes Area stores your answers for bookwork checks
  Seperate practice area for worded questions on a variety of togglable subjects
  Softens harsh, incorrect red colours for maximum focus

Known Issues:

  Some pages may not be of the correct colour, including times table menus. If issues occur either reload the page or turn off the overlay by toggling in the extension menu.
